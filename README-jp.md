【MOD名】 - TurboWarp向け高機能3D＆物理演算拡張MOD
TurboWarpの可能性を極限まで広げる、本格的な3DゲームエンジンMODです。
直感的なオブジェクト操作から、物理演算、さらには次世代のグラフィックス表現までをこの一本で実現します。
✨ 主な機能

* マルチフォーマット対応: OBJおよびgltf形式の3Dモデルをリストから直接読み込み可能。
* 柔軟なテクスチャ適用: PNG（ビットマップ）とSVG（ベクター）に対応。URL指定またはコスチュームから読み込めます。
* リアルな環境表現: リアルタイム光（ライト）、反射（リフレクション）、そしてフォグ（霧）エフェクトを搭載。
* RTX（レイトレーシング）対応: 超高画質なレイトレーシング機能をワンクリックでON/OFF可能（※現在ベータ版、デフォルトはOFF）。
* 物理演算（Physics）＆衝突検知: オブジェクト同士が触れているかを正確に検知。複雑な物理挙動を実装できます。
* 自由なオブジェクト操作: スクリプトからオブジェクトの生成、移動、回転が自由自在。

⚠️ パッケージ化（HTML/アプリ化）時の重要な注意点
プロジェクトをパッケージ化する際は、必ず以下の設定を確認してください。

* 「RAMを節約するために、読み込んだ後に元のデータを削除する」のチェックを外してください。
* ※このチェックが入っていると、テクスチャが正常に反映されない（表示されない）可能性があります。
