Unleash the full power of TurboWarp with this advanced 3D game engine extension!
From intuitive object manipulation to rigid-body physics and next-gen graphics, this MOD brings your 3D visions to life.
✨ Key Features

* Multi-Format 3D Models: Seamlessly load .obj and .gltf files directly from lists.
* Flexible Texturing: Supports .png and .svg formats. Load them via URL or directly from Scratch costumes.
* Realistic Environments: Built-in support for dynamic Lighting, Reflections, and Fog effects.
* RTX (Ray Tracing) Support: Toggle ultra-realistic ray tracing with a single click (Beta feature, turned OFF by default).
* Physics & Collision Detection: Accurately detect when objects touch each other to create complex physical interactions.
* Dynamic Object Control: Easily create, move, and rotate 3D objects via blocks.

⚠️ Important Notice for Packaging (HTML/Executable)
When exporting your project using the TurboWarp Packager, please ensure the following setting:

* UNCHECK "Remove original data after loading to save RAM".
* If this option remains checked, textures may fail to load or render properly in your packaged project.
